# 命令行式插件管理器

项目地址：[QuickupPlugMng: QuickUp命令行式插件管理器](https://gitee.com/captorking/quickup-plug-mng)

QuickUp要使用插件功能的机会不多（至少除了数据持久化，我没想到有什么是单独脚本不可方便替代的），应用内大概率不会添加UI管理功能。考虑到开发QuickUp插件需要看开发说明文档，使用者应当具备一定开发能力，因此额外提供了命令行式的插件管理器。

该管理器可用来浏览、搜索、协助创建、删除插件目录，方便快速初始化开发与已有插件管理。

不保证同步，大部分时候不处理提议，作者本人也几乎用不到。

# Command Line Plugin Manager 
Address: [QuickupPlugMng: QuickUp命令行式插件管理器](https://gitee.com/captorking/quickup-plug-mng)

The opportunity for QuickUp to utilize the plugin function is limited (at least except for data persistence, I couldn't think of anything that could be conveniently replaced by a standalone script). It is highly unlikely that the application will add UI management functions. Considering that developing QuickUp plugins requires reading the development documentation, users should have certain development capabilities. Therefore, an additional command-line-style plugin manager has been provided. 

This manager can be used for browsing, searching, assisting in creating and deleting plugin directories, facilitating the quick initialization of development and the management of existing plugins. 

There is no guarantee of synchronization. Most of the time, the issues are not processed. The author himself hardly uses them either.
