# QuickUp 4.9 以及源码

今天，发布了QuickUp-4.9版本，带来了性能优化、置顶任务功能修复和边框显示主题色的功能。

从这个版本开始，QuickUp的**基本**源码将保持开放和跟进。目前，QuickUp开源代码库和本地开发库依然是两个东西，靠我简单的手动更新。QuickUp开源代码库仅展示本地开发库的`main`分支，发行版由本地开发库的`pro`分支编译。截止 4.9 版本，发行版仅在关于界面上不同于开源版。

---

Today, the QuickUp-4.9 version was released, featuring performance optimizations, fixes for the pinned task function, and the ability to display the accent color of the border.

Starting from this version, the **basic** source code of QuickUp will remain open and updated. Currently, the QuickUp open-source code repository and the local development repository are two separate entities, **still**, and I manually update them. The QuickUp open-source code repository only shows the `main` branch of the local development repository, and the release version is compiled from the `pro` branch of the local development repository. As of version 4.9, the release version differs from the open-source version **only** in the *about interface*.
