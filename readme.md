# QuickUp

<a href="https://apps.microsoft.com/detail/9NGHF8PDF0DL?referrer=appbadge&mode=direct"><img src="https://get.microsoft.com/images/en-us%20dark.svg" width="200"/> </a>

一个**轻量高效的 Windows 应用组启动工具，一键搭建专属工作/娱乐环境**。

QuickUp 是一款专为 Windows 打造的轻量化、高效率批量启动工具，支持应用批量启动、命令批量执行、多工作区管理、窗口布局自定义等实用功能。极低的资源占用、简洁的交互设计、丰富的自定义能力，助力用户告别繁琐的软件手动启动操作，一键还原专属使用场景。

详情见[介绍](https://quickup.smart-space.com.cn/)。

> 虽然提供了微软应用商店下载方式，但仍然建议从“发布”页面获取安装包。
>
> 建议Windows10及以上的系统。

---

QuickUp is a lightweight and efficient batch startup tool for Windows\. It supports batch application launching, command execution, multi\-workspace management and window layout customization\. With low resource consumption and flexible customization, it helps users quickly restore exclusive usage scenarios\.

For detailed see [QuickUp's website](https://quickup.smart-space.com.cn/).

> Although the Microsoft Store download method is provided, it is still recommended to obtain the installation package from the "release" page.
>
> Windows10+ is recommended.

---

## ✨ 核心亮点

- **极简轻量**：体积小巧、低内存占用，可后台静默运行，不拖累系统性能

- **场景化批量启动**：一键启动多软件、执行多命令，支持子任务、子工作区嵌套

- **高度自定义**：热键、界面样式、窗口布局、任务标签、启动权限自定义

- **匹配搜索**：优化模糊搜索算法，大小写忽略、精准匹配任务

- **拓展性强**：内置基础插件系统，支持功能拓展，适配更多使用场景

- **人性化细节**：支持系统托盘后台运行、开机自启、窗口状态记录

- **任务窗口组预览**：类似Windows Snap的窗口组预览、呈现与一键调度

## 🎯 完整功能特性

### 🔧 批量任务管理

- 单任务自定义多应用、多命令组合，支持 CMD/PowerShell 双命令行模式

- 支持**并行/单线串行**双执行模式，可等待单任务结束后再接续执行

- 多层工作区嵌套，自定义工作区分组，分类管理各类场景任务

- 任务复制粘贴、隐藏任务、置顶收藏任务，灵活管理任务列表

### 🪟 窗口与场景定制

- 记忆并还原应用窗口位置、大小、圆角状态，贴靠窗口精准复原

- 支持管理员模式启动、窗口最大化/最小化启动，适配特殊使用需求

- 主窗口透明度可调，支持明暗主题、跟随系统样式

- 自动过滤不可缩放窗口，优化窗口适配逻辑

- 单个任务下参与排布的窗口会归为一个预览组，可以一键调度到前台

### ⌨️ 快捷操作体验

- 自定义全局热键，托盘静默运行，热键一键唤醒主窗口

- 主界面支持翻页、Home/End 快捷键快速切换任务

- 进程匹配忽略大小写，支持标签关键字精准检索

### ⚙️ 高阶配置能力

- 开机自启配置，支持静默后台启动，无感常驻系统
- 应用启动参数记录、自定义任务工作目录，子任务自动继承目录配置
- 标签系统管理任务，支持标签排序、批量关联任务，分类更清晰
- 命令行参数支持，可通过指令直接唤醒工作区、运行指定任务
